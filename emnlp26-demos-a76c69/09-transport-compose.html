Will the Edit Survive Deployment?

A model edit can pass every in-distribution check and still revert under paraphrase, and two interventions that each work alone need not work together. Transport and composition are separate claims, and each needs its own evidence.

What this shows

In the Transport tab, both tiles measure the same edited weights; the slider only changes which prompts the measurement runs on. The edit’s effect is concentrated around the template family it was fitted on, so an evaluation drawn from that family keeps reporting success no matter how far deployment traffic drifts. Whether the effect carries over to the deployment distribution is a transportability question: causal inference has formal criteria for when an effect transfers across distributions — roughly, the effect transports when the mechanism the edit changed is the same one the deployment prompts route through, a structural condition, not a promise that nearby prompts behave similarly — and editing pipelines typically leave that assumption unstated rather than testing it.

The Compose tab makes the control-side point. In the toy, a model edit is an assignment (a block of weights is set to whatever satisfies the new fact) while a task vector is an addition. Assignments to overlapping weights do not commute and do not compose: the second edit partially undoes the first — toggle them in the other order and the other behaviour loses — even though each passes its own evaluation, and the overlap slider shows the damage scales with the collision (at zero overlap, assignment composes too). Additions along disjoint directions compose linearly. Neither panel is the real mechanism inside a transformer; the point is that “each works alone” says nothing about “both work together”, so composition has to be established, not assumed.

What the paper says

“Failures of model editing (Cohen et al., 2024; Hoelscher-Obermaier et al., 2023) are predictable consequences of unexamined transportability assumptions (Bareinboim et al., 2022).” — Call to Action, “Transportability as a Theory of Edit Generalisation”, arXiv:2602.16698
“Compositionality varies across intervention types: model edits do not compose (Hoelscher-Obermaier et al., 2023), while task vectors compose linearly (Ilharco et al., 2022).” — Call to Action, “Compositional Control”, arXiv:2602.16698

Try this

  1. Move the deployment slider slowly and find the point where the two tiles first disagree. Nothing about the model changed between those two slider positions. What would the evaluation set have to contain to catch this divergence before deployment?
  2. At far shift, toggle the edit off and on. The in-distribution tile flips between 0/8 and 8/8; the deployment tile barely reacts. Which claim did the green tile license: “the model now states Vora”, or “the model states Vora on prompts like the ones we tried”?
  3. In the Compose tab, apply A, then add B, and watch behaviour A in the left panel; reset and apply them in the opposite order, and B loses instead. Then take an editing or steering paper you know: does its evaluation ever apply two interventions at once? One of the paper’s research questions asks exactly this: under what conditions do representation-level interventions compose additively?
