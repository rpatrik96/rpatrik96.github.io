Same Loss, Different Story

A sparse two-dimensional source, mixed and learned back by an autoencoder — reconstruction plus a sparsity penalty is exactly the sparse-autoencoder (SAE) objective from the paper’s Proxy Gaming case study. Rotate the learned basis by θ: reconstruction never notices, sparsity near-ties two different bases, and only an identifiable objective — one whose assumptions guarantee the true basis is recoverable — points back to the true axes.

Which story does each objective tell?

Reconstruction

Can distinguish: whether the encoder–decoder pair reproduces the data. Cannot distinguish: any two invertible remixings of the latents — every θ scores exactly the same.

+ only sparsity

Can distinguish: some bases from others — the curve is not flat, so it does prefer angles. Cannot distinguish: its two near-tied minima — 0.78 at the mixed 40° basis versus 0.80 at the true axes — so which basis training returns is optimisation luck.

Identifiable model

“Identifiable” = an objective whose assumptions guarantee the true basis is recoverable. Can distinguish: the true axes from every mixed basis — minima exactly at 0° and 90°. Leaves open: elementwise indeterminacies — permutation and sign: swapping latent 1 with latent 2, or flipping a sign, relabels latents but never mixes them.

What this shows

The flat green line is the paper’s identifiability argument made visible. For an autoencoder pair (q, r) trained on reconstruction, any invertible transformation a of the latents yields a different pair (q ∘ a, a−1 ∘ r) with exactly the same objective value — a rotation of the basis is one such transformation, so reconstruction cannot prefer any θ over any other. Whatever per-latent story you tell at θ = 0° — the paper’s own example: “latent i is speech”, “latent j is music” — an equally good solution at θ = 35° has every feature part speech, part music, and the training objective cannot see the difference.

Adding an ℓ1 sparsity penalty makes the loss reconstruction-plus-sparsity — exactly the sparse-autoencoder (SAE) objective in the paper’s Proxy Gaming case study. It breaks the flatness but not the tie that matters: this point cloud is one-sparse in two different bases, so the penalty near-ties the mixed 40° basis (0.78) with the true axes (0.80), and which basis training returns is optimisation luck. That is the paper’s point about sparsity as an inductive bias rather than a guarantee, and its point about proxy metrics: unsupervised scores such as reconstruction and sparsity provide little evidence about the structure a model has learned (the paper cites Locatello et al., 2019, for this failure mode). An identifiable objective — one backed by assumptions under which the true basis is recoverable — has its minima exactly at 0° and 90°: the two angles where the learned axes coincide with the true ones, up to the permutation-and-sign indeterminacies (swap two latents, or flip a sign) that relabel latents without mixing them.

What the paper says

“without identifiability, fitting a latent variable model recovers some latent coordinates that reproduce the observed distribution, such that any invertible remixing of these coordinates (such as, a rotation, or even a nonlinear reparameterisation) yields the same solution under the designed objective” — §“The Right Question Is Not Enough. Answers Must Be Identifiable”
“Multiple sparse factorisations can achieve similar objective values. Thus, while sparsity is a useful inductive bias, it does not guarantee identification.” — Case Study II: Proxy Gaming, §“A Unified Causal Lens Predicts Interpretability Failure Modes”

Try this

  1. Set θ to 40° and defend the claim “our autoencoder recovered the right basis” using only the three read-outs. Which objective exposes the claim, which one rates this mixed basis a hair better than the true axes, and which one stays silent?
  2. Reconstruction is flat at 1.00 for every θ. State the property of the transformation family that makes this exact rather than approximate — and why the same argument covers nonlinear reparameterisations, not only rotations. (Hint: what happens to the composed pair (q ∘ a, a−1 ∘ r) for any invertible a?)
  3. With a partner: the identifiable curve has minima at both 0° and 90°. What indeterminacy do the two minima reflect, and why does it leave per-latent semantics intact when a 40° blend does not?
