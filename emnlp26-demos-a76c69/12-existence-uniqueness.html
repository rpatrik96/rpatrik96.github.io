Circuit discovery proves existence, not uniqueness

One network, one dataset, one ablation baseline, one stopping threshold. A new run changes only the seed that orders the pruning search, and it can return a different “minimal circuit” at exactly the same faithfulness.

Press Run circuit discovery. Each run starts from the full network and greedily prunes components while faithfulness stays above the threshold τ (0.95 by default; the slider on the right changes it); the seed only shuffles the order in which components are considered for removal. Network weights, dataset, zero-ablation baseline, and metric are frozen across runs — and within one sweep, so is τ.

What each run establishes ∃ S : p(y ∣ do(hS̄ := 0)) ≈ p(y) An existence result: some sufficient subgraph. Keep S, zero-ablate the rest (S̄), and behaviour is preserved — exactly the F(S) ≥ τ test the meter narrates. Every run above delivers this, and every run’s evidence is genuinely interventional. do(·): pin activations to chosen values — the causal notation for patching/ablation.
What “the mechanism” would need ∃! S (mod ∼) An identification result: uniqueness up to a stated equivalence class ∼. In plain words: exactly one circuit (∃!), once you declare which circuits count as the same (∼). The gallery above is a direct counterexample for the toy.
What would rule out alternatives In the paper’s words: “One would need to introduce certain constraints to identify a more unique solution.” The paper also notes this is not a rung-level (observational- vs interventional-evidence) mismatch — the evidence is already interventional; it fails to rule out alternative values of the estimand (the quantity the experiment is designed to pin down). Short of identifying constraints, the honest unit of report is the equivalence class of circuits, not one member of it.

What this shows

Every run performs the same backward-pruning search over the same frozen network; the seed enters only through the order in which components are tested for removal, a stand-in for the initialisation and optimisation choices that real discovery pipelines make — mask initialisation, edge ordering in automated circuit discovery (Conmy et al., 2023), stopping heuristics. The toy contains a duplicated signal head and redundant readers by construction, so four different two-component subgraphs each reconstruct the model’s behaviour exactly. Which one a run returns is decided entirely by the seed, and at the default τ all four score the same faithfulness to every decimal shown: their patching effects are identical, so no experiment on this page can tell them apart. After four distinct circuits, the intersection tile reads none — not a single component is shared by all of the reported “mechanisms”. Raising τ with the slider repeats the story one level up: circuits must now keep the weak 0.246·d distractor pathway, so they grow to four or five components (around τ ≈ 0.98–0.99, even which distractor head survives varies by seed, and the faithfulness spread goes nonzero) — yet the set of admissible circuits never shrinks to one.

This is the paper’s Existence ≠ Uniqueness mismatch. Interventional evidence establishes that a sufficient subgraph exists (∃S), while calling the result “the mechanism” admits a stronger reading that would require uniqueness up to a stated equivalence class (∃!S mod ∼). The paper’s method taxonomy scopes circuit evidence the same way: “Existence of a sufficient path is identified; uniqueness and necessity are not” (Zhang & Nanda, 2024; Chan et al., 2022). Until additional constraints rule out the alternatives, the paper’s takeaway applies verbatim to the gallery above: the uncovered subgraphs are “intervention handles, and not unique explanations”.

What the paper says

“However, multiple circuits can produce identical patching effects: the observation that patching component C restores behavior does not rule out alternative components C′ that would do the same.”

— method taxonomy, “Causal and Circuit-Based Methods”, arXiv:2602.16698

“The method identifies one member of an equivalence class of sufficient circuits, and which one it returns depends on initialisation, optimisation choices, etc.”

— mismatch box “Existence ≠ Uniqueness”, arXiv:2602.16698

Try this

  1. Run discovery twice and compare the first two cards. Nothing about the model changed between the runs. If run 1 had been a paper reporting “the circuit for s”, what exactly does run 2 refute — the experiment, or the word “the”?
  2. Keep running until the “components in every circuit” tile reads none (four distinct circuits suffice). Every report came with the same faithfulness score, yet no component is common to all of them. Which circuit claims that you know from the literature would survive a seed sweep like this one?
  3. The ablation-strategy demo on this site changes the baseline and gets a different circuit; this demo sweeps the search seed — and, with the slider, the threshold τ. Sweep τ to both extremes: circuits shrink to two components or grow to five, yet the set of admissible circuits never collapses to one. List the remaining degrees of freedom (metric, dataset, component granularity) and discuss which constraints — necessity tests, hypothesis-testing frameworks such as causal scrubbing (Chan et al., 2022), or an explicitly declared equivalence class — would shrink that set.
