Sufficient ≠ necessary: a handle is not the mechanism

A toy network carries the same IOI-style signal along two redundant pathways. Denoising path S restores the corrupted run — real evidence that S is a sufficient handle. Noising the very same path barely moves the clean run, because backup path T keeps the behaviour alive. The claim-o-meter tracks which narrations the evidence you have actually gathered will license, and a backup-strength slider lets you shrink the redundancy until the necessity verdict flips.

Two baseline runs anchor the output meter; the four patching experiments each copy one pathway’s activation between runs (denoising: clean → corrupted run; noising: corrupted → clean run). Each experiment button keeps its result as a badge: P(Mary) before → after that patch. Run an experiment, watch the output, then check the claim-o-meter.

What this shows

The toy routes one signal — here, the IOI-style cue that the giver is John, so the next token should be “Mary” — through two redundant pathways, and its readout follows whichever pathway carries the stronger value. Denoising S — patching its clean activation into the corrupted run — fully restores the output, which is exactly the evidence activation patching yields, and it is real evidence: S is a working control handle for the behaviour. Noising S — patching the corrupted activation into the clean run — barely moves the output, because path T still carries the signal. The same component under two patching directions answers two different questions: denoising tests sufficiency, noising tests necessity, and in this network the answers diverge by construction. The backup-strength slider makes the reason tangible: drag wT toward zero and the necessity verdict flips, because redundancy is exactly what lets sufficiency and necessity come apart.

This is the paper’s Case Study I in miniature. Patching evidence sits on the interventional rung (L2) of Pearl’s causal ladder, the three-rung hierarchy of causal questions: L1 observes, L2 intervenes (what happens if we do x), L3 reasons counterfactually (what would have happened otherwise). “S is the mechanism”, by contrast, asserts necessity and uniqueness — counterfactual (L3) claims that the L2 result establishes for neither; the claim-o-meter marks that narration as rung-elevated until noising-style evidence arrives. One subtlety deserves a sentence: the noising experiment that refutes necessity is itself an L2 intervention, and it can settle the L3 claim here only because the toy is deterministic, so noising computes the counterfactual exactly. In real stochastic models noising is a practical proxy: L2 evidence can refute a necessity claim, but never establish it. The redundancy is not an artifact of the toy: Wang et al. (2023) find multiple redundant circuits for the same Indirect Object Identification task, and McGrath et al. (2023) document emergent self-repair in language model computations, where alternative pathways compensate for ablated ones. Running both patching directions, as Heimersheim and Nanda (2024) advocate, is the paper’s recommended practical step — here it takes one extra button press to overturn the “THE mechanism” reading.

What the paper says

“The mechanism asserts necessity and uniqueness, but the evidence establishes neither. Other pathways S′ ≠ S may be equally sufficient, and sufficiency (intervention changes output) does not entail necessity (without S, output would have been different).”

— mismatch box “Case Study I: Sufficient ≠ Necessary”, arXiv:2602.16698

“Patching identifies only a sufficient (but not necessary) control handle; necessity requires L3 evidence. […] Testing for both denoising (sufficiency) and noising (necessity), as advocated by Heimersheim and Nanda (2024), is one practical step toward closing this gap—their recommendation has a direct theoretical grounding.”

— takeaway of the same mismatch box, arXiv:2602.16698

Try this

  1. Run Denoise S only and stop — the typical patching workflow. The sufficiency row turns green while the “THE mechanism” row reads not licensed. Which of the three narrations would the abstract of a paper reporting this experiment most likely have used?
  2. Now run Noise S. The clean run’s output barely moves. One extra experiment on the same component flips the necessity verdict — what does that imply for circuit papers that report only denoising results?
  3. Run Denoise T. Both pathways are near-equally sufficient, so the equivalence class of sufficient circuits — the set of circuits this evidence cannot tell apart — has two members by construction. In a real model, where the amount of redundancy is unknown, what evidence would license calling any component set “the” mechanism?
  4. With all badges in place, drag Backup strength wT toward zero and watch the claim-o-meter: sufficient-but-not-necessary turns into sufficient-and-necessary as the redundancy vanishes. What does the flip tell you about why the two notions diverge in the first place?
